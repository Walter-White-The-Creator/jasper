# 🍄 Super Mario Web Spel

> *Het is-a me, Mario!*

Een browser-gebaseerd Mario spel gebouwd met HTML, CSS en JavaScript. Klik op het vraagteken blok, verzamel punten, en pas op voor Bob de Bom! 💣

---

## 🎮 Hoe speel je het?

1. Ga naar de [spelpagina](https://walter-white-the-creator.github.io/jasper/)
2. Klik op het **vraagteken blok** om punten te verdienen
3. Kies **Yoshi** 🥚 of **Luigi** 👨‍🔧 voor een verrassing
4. **BLIJF VAN BOB DE BOM!** 💣

---

## ✨ Functies

- 🖱️ Klikspel met punten teller
- 🎉 Melding om de 10 punten, 20 punten, 100 punten en 1000 punten!
- 🥚 Yoshi knop → Yoshi pagina
- 👨‍🔧 Luigi knop → Luigi pagina
- 💣 Bob de Bom knop → je bent gewaarschuwd...
- 🌄 Mario achtergrond
